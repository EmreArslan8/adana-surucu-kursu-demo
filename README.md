# Adana Şehir Sürücü Kursu — demo

Veri odaklı statik site üreticisi (bağımlılık yok). İçerik `data/` altında, şablonlar `src/` altında.

```bash
npm run build   # dist/ üretir (HTML + sitemap.xml + robots.txt)
npm run dev     # build + http://localhost:4400
```

Demo amaçlıdır; iletişim bilgileri örnektir, görseller Unsplash'ten.
